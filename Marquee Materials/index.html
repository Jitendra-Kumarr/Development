0. What is CSS?

HTML is the structure of a house — the walls, the rooms, the doors. CSS (Cascading Style Sheets) is the decoration — the wall colors, the furniture style, the lighting. CSS is what makes a website look good instead of just plain black text on a white page.

The Basic Syntax

Every CSS rule has three parts: a selector (what to style), a property (what aspect to change), and a value (what to change it to).
selector { property: value; } /* Real example: */ p { color: blue; font-size: 18px; }
  • p is the selector — it means "every paragraph on the page."
  • color and font-size are properties.
  • blue and 18px are values.
  • Every line MUST end with a semicolon ; — this is the most common beginner mistake to forget!
  • The whole rule is wrapped in curly braces { }.
How CSS connects to HTML: You can write CSS inside a <style> tag in your HTML file, or in a separate .css file linked with <link rel="stylesheet" href="style.css">. In this practice sheet, we're writing CSS directly for you to experiment with.

1. Selectors — Telling CSS What To Style

A selector decides WHICH element(s) on the page get styled. There are several types:
h1 { } /* Element selector - ALL h1 tags */ .myclass { } /* Class selector - anything with class="myclass" */ #myid { } /* ID selector - the ONE element with id="myid" */ * { } /* Universal selector - EVERY element */ h1, p { } /* Grouped selector - both h1 AND p */
Analogy: An element selector is like saying "all students in the school." A class selector is like "all students in Class 5B" (many students can share a class). An ID selector is like "the student with Roll Number 7" — only one person can have that exact roll number.
  • Class names in CSS start with a dot: .fruit
  • ID names in CSS start with a hash: #special
  • In HTML, you attach them like: <p class="fruit" id="special">
  • You can use MANY classes on one element, but only ONE id.

2. Colors & Backgrounds

You can write colors in CSS in several ways:
  • Named colors: red, blue, teal — easy but limited (147 names exist)
  • Hex codes: #ff0000 — 6 characters representing Red-Green-Blue in hexadecimal. #ff0000 is pure red, #000000 is black, #ffffff is white.
  • RGB: rgb(255, 0, 0) — same idea but written as three numbers (0–255)
  • RGBA: rgba(255, 0, 0, 0.5) — same as RGB but with a 4th number for transparency (0 = invisible, 1 = fully solid)
Two different properties: color changes TEXT color. background-color changes the BACKGROUND color of the box. Beginners often mix these up!

3. The Box Model — The Most Important Concept

Every single element on a webpage is secretly a rectangular box — even text and images. Understanding this box is the key to controlling layout. Each box is made of 4 layers, from the inside out:
  • Content — the actual text or image inside
  • Padding — transparent space BETWEEN the content and the border (inside the box)
  • Border — the visible line around the padding
  • Margin — transparent space OUTSIDE the border (pushes other elements away)
The Photo Frame Analogy: Imagine a framed photo hanging on a wall:
• Content = the photo itself
• Padding = the white cardboard space between the photo and the wooden frame (INSIDE the frame)
• Border = the wooden frame itself
• Margin = the empty wall space between this frame and the next picture hanging next to it (OUTSIDE the frame)
The key difference to remember: padding pushes the border outward (grows the box), while margin pushes other elements away (the box's own size doesn't change — it's the space around it).

4. Margin — Space Outside the Box

Margin creates space AROUND an element, pushing away from its neighbors. It is always invisible/transparent — you'll never see a color there.
.box { margin: 20px; /* all 4 sides = 20px */ margin-top: 10px; /* only top */ margin-right: 15px; /* only right */ margin-bottom: 10px; /* only bottom */ margin-left: 15px; /* only left */ }

Shorthand — Setting All Sides at Once

Instead of writing 4 separate lines, you can combine them. The order always goes clockwise starting from the top: Top, Right, Bottom, Left. A good trick to remember the order is the word "TRouBLe".
margin: 10px 20px 30px 40px; /* top right bottom left */ margin: 10px 20px; /* top&bottom = 10px, left&right = 20px (2 values) */ margin: 15px; /* all four sides = 15px (1 value) */

5. Padding — Space Inside the Box

Padding creates space INSIDE an element, between its content and its border. Unlike margin, padding IS filled with the element's background color — it's not invisible.
.box { padding: 20px; /* all 4 sides */ padding-top: 10px; padding-right: 15px; padding-bottom: 10px; padding-left: 15px; } /* Shorthand works the same way as margin */ padding: 10px 20px 30px 40px; /* top right bottom left */

6. Border

A border needs THREE things to be visible: a width (how thick), a style (solid, dashed, dotted, double), and a color. If you forget the style, the border won't show at all — this is a very common mistake!
.box { border-width: 3px; border-style: solid; border-color: red; /* or all in one line (shorthand): */ border: 3px solid red; }

9. Display Property

The display property controls how an element behaves in the layout flow:
  • block — takes up the full width available, always starts on a new line (e.g. <div>, <p>)
  • inline — only takes as much width as its content needs, sits on the same line as neighbors, and width/height DON'T work on it (e.g. <span>, <a>)
  • inline-block — best of both: sits on the same line AND respects width/height
  • none — completely hides the element (removes it from the page)

10. Position Property

position controls how an element is placed relative to the normal flow:
  • static — the default, normal flow, top/left/right/bottom have no effect
  • relative — stays in normal flow, but you CAN nudge it using top/left/right/bottom, relative to where it WOULD have been
  • absolute — removed from normal flow, positioned relative to its nearest ancestor that has position: relative (or the page if none)
  • fixed — stays glued to the same spot on screen even when you scroll

11. Flexbox — Aligning Items Easily

Flexbox is the modern way to arrange items in a row or column. Put display: flex on the PARENT, then use justify-content (horizontal alignment) and align-items (vertical alignment) to position the children.
.parent { display: flex; justify-content: center; /* left, center, right, space-between... */ align-items: center; /* top, center, bottom */ gap: 10px; /* space between items */ }
